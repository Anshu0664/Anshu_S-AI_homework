Question Title: Data Breach Response
Question Link : https://my.newtonschool.co/playground/code/orlr84xpc3oo?lecture_hash=vifkrugjcwth

Solution :
cd breach_response
cp evidence/log_dump.txt log_dump.txt
chmod 755 evidence
mv evidence secure/evidence
chmod 555 secure/evidence
chmod 644 reports/incident_summary.txt
echo "Breach confirmed" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt
echo "Forensics Complete" >secure/forensics_report.txt
chmod 600 secure/forensics_report.txt
chmod 644 reports/incident_summary.txt
echo "Escalated to security team" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt

Approach :
First, I entered the "breach_response".
Then, I copied "log_dump.txt" from the "evidence" folder
then, I changed the permission of evidence folder to 755
then I moved it into secure folder,
And after I restored its permission to 555.
Again I changed the permission of incident_summary.txt to 644
then I append the line "Breach confirmed" in it
And after that I restored its permission to 444
then I created a file name forensics_report.txt inside secure folder
And then I write "Forensics Complete" in it
then I set permission to 600
then, I again changed the permissions of incident_summary.txt to 644
and then I append the line "Escalated to security team" in it
and then restored its permission to 444
